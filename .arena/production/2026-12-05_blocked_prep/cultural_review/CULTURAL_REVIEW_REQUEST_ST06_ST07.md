# Cultural Review Request — ST06 Ritual / ST07 Festival (EXCLUDED states)
Status: **EXCLUDED pending cultural review.** No visuals, concepts or 3D will be produced for these states before review. This package prepares the review so it can start immediately when a reviewer is engaged.
## What we are asking a reviewer to decide
1. Whether ritual/festival states may be depicted at all in this fictionalised setting, and at what level of specificity (evocative vs explicit).
2. Which elements are documented, which are sensitive/restricted, and which must never be depicted.
3. Whether invented-but-respectful ceremonial design is acceptable, and under what constraints (the project already treats e.g. the spiral pendant as declared fiction, never as an Igbo emblem).
4. Review/approval workflow: who signs off concepts before production, and what records must be kept.
## Design commitments going in
- Documented-evidence vs artistic-interpretation split recorded for every element (existing practice).
- No masks, regalia, sacred objects or ritual choreography designed pre-review.
- Uncertainties stated, never presented as historical certainty; no generic "African festival" substitutes.
## Reference gaps (to be filled with the reviewer, not by image generation)
Region/period-specific scholarship on Igbo ceremonial life appropriate to the game's framing; museum/collection references the reviewer endorses; community consultation route if the reviewer requires it.
## Unblock condition
Named reviewer + written answers to 1-4 -> Design then runs research -> concepts -> review -> accept/reject cycle. Until then these states stay EXCLUDED in every register/report.
