# W1 D7 BLENDER WORKSTATION EXECUTION PACKAGE — Adanna AD-03 V2 + Guard V1
**One procedure. No troubleshooting required. Target: Apple Silicon Mac (M1/M2/M3/M4).**
This package turns the two shipped skinned GLB models into native Blender projects (`.blend`), Unreal-ready FBX exports, and QC preview renders. It does **not** rebuild the characters from scratch — the GLBs are the qualified source (built by the scripts listed in §2), and Blender is the finisher/validator.

## THE PROCEDURE (do exactly this)
1. Install **Blender 4.2 LTS** (see §1) if not already installed.
2. Open Terminal, go to the repo checkout, and run:
   ```bash
   cd TDD/.arena/production/2026-11-24_w1d7_blender_package
   ./run_all.sh
   ```
3. When it prints `DONE`, open the 8 preview PNGs in `output/*/previews/` and eyeball them (§7).
4. Commit the `output/` folder back to branch `arena/6e649a9b-tdd` (or hand the folder to Design/PM).
Total hands-on time: **~2 minutes**. Machine time: **~2–5 minutes** (§6).

## 1. Exact Blender version required
- **Blender 4.2 LTS, macOS Apple Silicon (arm64) build** — qualified version. Any 4.2.x patch (4.2.0–4.2.x LTS) is accepted by the runner; other 4.x versions run with a warning path in the script header check (4.x accepted, 4.2 LTS is the tested target). 3.x / 5.x are rejected by `run_all.sh`.

No other installs: **no Python/pip packages, no Xcode, no system graphics libraries** — Blender.app is fully self-contained on macOS, and the finisher runs inside Blender's bundled Python in background mode (`-b`).
- OS: macOS 13 Ventura or later (Apple Silicon native).

## 4. Exact commands executed
`run_all.sh` runs, per character (shown for Adanna):
```bash
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup \
  --python .arena/production/2026-11-24_w1d7_blender_package/blender/finish_character.py \
  -- --input .arena/production/2026-11-23_w1d7_production/adanna/out/ADANNA_AD03_V2.glb \
     --name ADANNA_AD03_V2 \
     --outdir .arena/production/2026-11-24_w1d7_blender_package/output/ADANNA_AD03_V2
```
Before that it: locates Blender (`$BLENDER`, `/Applications`, `~/Applications`, PATH), asserts 4.x, and verifies both GLB checksums. After Blender, it re-runs the pure-Python deformation test into `output/*_DEFORM_RECHECK.json` (skipped silently if `python3` is absent).

## 7. Automated validation + visual inspection
Automated (already in the run): checksum gate → in-Blender validation (mesh/armature presence, triangle count, weight sums, unweighted-vertex count = 0, height, bone count) → pose-deformation test (evaluated mesh must move for elbow/shoulder/knee/neck) → post-run pure-Python LBS deformation re-check (8 poses; shipped results from Design sandbox: PASS, rest-pose identity 0.000 m).
Visual (2 minutes, human): open the 8 PNGs. Check: character upright, ~head-to-floor framing; Adanna — indigo wrap/skirt, baldric diagonal L→R, coils on the LEFT arm, pendant at chest, hair knot; Guard — one-shoulder wrap, waist sash, plain armband, empty hands. Any gross import fault (lying flat, exploded parts, missing limbs) = fail → §8.

## 8. Recovery instructions (match the error, do only that step)
| Symptom | Action |
|---|---|
| `ERROR: Blender not found` (exit 3) | Install Blender 4.2 LTS (Apple Silicon) into `/Applications`, re-run `./run_all.sh`. If Blender lives elsewhere: `BLENDER=/path/to/Blender ./run_all.sh` |
| `Blender 4.x required` (exit 3) | Install 4.2 LTS alongside; point `BLENDER=` at the 4.2 binary if a newer default exists |
| `missing input: …` (exit 4) | Wrong/shallow checkout: `git fetch && git checkout arena/6e649a9b-tdd && git pull`, re-run |
| `input checksum mismatch` (exit 4) | Same as above — do not edit the GLBs; the package is qualified against the hashed files |
| `FINISHER FAIL: Icosphere: no vertex groups` | **Fixed in finisher v1.1** (that object is Blender's own bone-shape helper — see `ROOT_CAUSE_ICOSPHERE.md`). `git pull` this package and re-run `./run_all.sh` |
| `FINISHER FAIL: …` + QC JSON written | Read the one-line `error` in `output/<NAME>/<NAME>_BLENDER_QC.json`, send that file + the terminal log to Design; do not edit scripts. Design fixes script-side (you will get a one-commit update, then re-run) |
| Previews look wrong (flat/exploded) | Send the 4 PNGs of that character to Design with the QC JSON; do not attempt manual repair |
| Partial run (one character done) | Just re-run `./run_all.sh` — it is idempotent and overwrites its own outputs |
| Gatekeeper blocks first Blender launch | Right-click Blender.app → Open → Open (once), then re-run |
