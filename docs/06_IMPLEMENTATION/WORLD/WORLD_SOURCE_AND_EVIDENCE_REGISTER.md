# TDD — World Source & Evidence Register

**Document ID:** TDD-IMPL-WORLD-006 · **Version:** 1.0 · **Date:** 2026-11-21
**Companion to:** `WORLD_SCALE_AND_LIVING_WORLD_BLUEPRINT.md` (TDD-IMPL-WORLD-001) and all world documents.
**Owner:** Research (evidence) / PM (categorisation & review). **Every decision is tagged and sourced. No invented names, deities or rituals are treated as canon.**

**Categories:**
- **[H] Historically documented** — well-supported by sources; may be used directly.
- **[R] Regionally documented, unverified** — reported in sources but varying/unconfirmed; use with care, flag for cultural review.
- **[A] Reasonable creative adaptation** — grounded in a real practice, adapted for the game; requires cultural review before canon.
- **[F] Fictional invention** — invented for the game; kept distinct from real practice.
- **[U] Unresolved** — needs research/cultural review/owner decision.
