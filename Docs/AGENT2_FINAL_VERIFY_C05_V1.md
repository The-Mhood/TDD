## 3. Check 2 — DV-22 negated-ownership correction `ABSENT`

**Classification: material blocker — the correction described by the task does not exist at the
target commit.**

The positive form that attributes the cue is in `docs/validation/dv_c05.py` at **line 625**
(inside `FORWARD_OWNER`):

```python
re.compile(r'\baudio\b[^.;|]{0,40}?\bbelongs?\s+to\s+' + AGENT1 + r'\b', re.I),
```

The defect is a **detector gap in `NEG_BEFORE` (lines 516–548)**, not a scope-rule gap. A denial is
recognised in one of two ways: `NEG_BEFORE` (a denial pattern whose match *spans* the mention) or
`NEG_AFTER` (a denial that follows the mention). For a determiner-quantified subject denial the
negative word precedes the noun — `No audio cue …`, `None of the audio cues …`, `There is no audio
cue that …` — and no `NEG_BEFORE` pattern matches that shape. Every existing `NEG_BEFORE` entry
requires a **verb** before `no` (`owns no`, `has no`, `carries no`) or a denial **noun** after it
(`no … responsibility`, `no … ownership`); none accepts `no` + modifiers + `audio` as a subject.

Because no `NEG_AFTER` pattern matches these sentences either, the code never enters the
`_UNIVERSAL` scope guard at line 605 — that guard is nested *inside* the `NEG_AFTER` loop. I measured
this directly rather than inferring it:

| Probe | `NEG_BEFORE` hits | `NEG_AFTER` hits | `negated_mention` | line 605 reachable |
|---|---|---|---|---|
| `No audio cue belongs to Agent 1.` | `[]` | `[]` | `False` | **no** |
| `There is no audio cue that belongs to the first agent.` | `[]` | `[]` | `False` | **no** |
| `None of the audio cues belong to the first agent.` | `[]` | `[]` | `False` | **no** |

So `negated_mention` returns `False` and `attributed_to_agent_1` returns `True` (line 625), producing
an offence. **Widening `_UNIVERSAL` at line 562 would therefore have no effect on any of these three
probes** — an earlier draft of this review recommended exactly that, and it was wrong. Corrected in
§11.

**Reproducible evidence.** Injecting each line into live text immediately before `## 9. Shared
read-surface` in a copy of the reviewed document:

| Exact input | Expected | Actual at `f1beb0c` |
|---|---|---|
| `No audio cue belongs to Agent 1.` | PASS | **FAIL** ❌ |
| `There is no audio cue that belongs to the first agent.` | PASS | **FAIL** ❌ |
| `None of the audio cues belong to the first agent.` | PASS | **FAIL** ❌ |
