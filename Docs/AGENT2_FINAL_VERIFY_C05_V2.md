## 9. F-1 — **Material blocker**: the new denial patterns excuse a real offence on the same line

**This is the only finding that warrants a revision, and it is a regression against S4.3.7.**

The three constructions added at `dv_c05.py:535–547` to close `CONDITION-1` allow their internal gap
to be any character except `.`, `;` and `|`:

```python
re.compile(r'\b(?:no|none\s+of\s+the)\s+' + _MODS + r'audio\b[^.;|]{0,50}?'
           r'\bbelong(?:s)?\s+to\s+' + AGENT1 + r'\b', re.I),
```

That gap **crosses a comma and a conjunction**. So a denial that opens the line suppresses a genuine
ownership assertion later in the same line, even when a clause boundary separates them. Compare
against `_NOT_CROSS`, which the module already defines for exactly this purpose at `dv_c05.py:561`
and uses for `NEG_AFTER`.

**Reproducible:**

```
inject into live text immediately before '## 9. Shared read-surface'
```

| Input | S4.3.7 | S4.3.8 | Required |
|---|---|---|---|
| `No audio cue is assigned to Agent 2 and the audio cue belongs to Agent 1.` | **FAIL** ✅ | **PASS** ❌ | FAIL |
| `No audio cue is provided for Agent 2, but the audio cue belongs to Agent 1.` | **FAIL** ✅ | **PASS** ❌ | FAIL |
| `No audio cue is assigned to Agent 2; the audio cue belongs to Agent 1.` | FAIL ✅ | **FAIL** ✅ | FAIL |
| `The audio cue belongs to Agent 1.` (control) | FAIL ✅ | **FAIL** ✅ | FAIL |

Each of the first two lines **asserts that Agent 1 owns the audio cue**. The denial in the opening
clause is about Agent 2. The `;` form is still caught, because `;` is in the excluded set, which is
what isolates the cause to the gap class rather than to the denial logic as a whole.

**I instrumented the module to prove causation rather than infer it.** Removing only the three
S4.3.8 patterns, with nothing else changed, restores both failures:

| | `and` form | `but` form |
|---|---|---|
| S4.3.8 as published | PASS ❌ | PASS ❌ |
| three new patterns removed | **FAIL** ✅ | **FAIL** ✅ |

**Why the suite cannot see it.** `TD-84` is the control that proves the positive form was not
weakened, and it uses a *separate* line (`The audio cues belong to the first agent.`). No case
places a quantified denial and a real offence on the **same** line, so all 120 cases pass while this
class is open — the same shape of blind spot as `CONDITION-2` at S4.3.7, and the reason a green
suite is not evidence of completeness.

**Scope: small and mechanical.** The escaping constructions are the two that allow a gap before the
possession verb. Excluding the conjunction/comma class from that gap — or reusing `_NOT_CROSS`, which
the module already has — is a bounded edit to three lines, not a redesign. **I verified the diagnosis
and did not attempt the fix**: designing the correction is Agent 1's work, not the reviewer's, and a
half-tested patch from me would be worse than a precise report.

**Why this is a material blocker and not a non-blocking observation.** `DV-22` is fail-open here: it
accepts a document that states an ownership assignment the contract forbids. That is the failure
direction the check exists to prevent, on a page where `TN-C-15` says the cue has one owner. My
`CONDITION-1` was fail-closed and I treated it as one condition; this is the other direction and I
will not grade it more gently.
